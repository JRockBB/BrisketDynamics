This directory records an unsuccessful attempt to replace the unchecked Gaussian remainder with direct, deterministic integration of the original nonlinear posterior. **Consistency has not been established and the production estimator has not been replaced.**

The development fixture is the already exposed core-only seed 3005, nx=4, with observations at 0, 120, 600 and 1800 seconds. Its frozen target has 17 static parameter coordinates and 116 initial/process coordinates. The Gaussian state squared error divided by dimension is 11.351421. An independent 32,768-draw importance reference gives 1.242357, with its existing estimated Monte Carlo precision gate passing (ESS 7784.85; minimum tail ESS 578.23). This is a diagnostic comparison on one cook, not a coverage test or validation of the reference against every possible mode. Monte Carlo was used only for this diagnostic reference.

The earlier affine result differs from the independent reference by at most 0.07011 marginal standard deviations in its mean and 5.826% in marginal standard deviation. Its unresolved quadrature status still prevents accepting it as a replacement. The two parameter-only experiments also contain an unvalidated Gaussian approximation to conditional state uncertainty; they are neither exact integrations nor successful fixes.

A separate check of the ODE evaluation at twelve deterministic directions tightened the solver tolerances by 10,000. The largest potential change was 2.13e-5 and the largest standardized output change was 5.87e-4. On those directions, the ODE precision did not explain the much larger integration discrepancies. No ODE tolerance was changed in production.

The implementation corrected two defects discovered in its own tests: shared Julia closure temporaries corrupted parallel moment evaluations, and a sparse quadrature could miss a higher-order interaction behind vanishing lower-order contributions. Explicit local temporaries fix the first. Broader interaction refinement and a fixed independent coordinate rotation check address the reproduced second failure. The remaining error indicators are estimates, not certified bounds or guarantees of finding every mode.

The current source lives in estimator/src/direct_quadrature.jl and estimator/scripts/direct_{transport,posterior,online}.jl. The new scripts are explicitly included experimental APIs. They retain full nonlinear history and analytically marginalize Gaussian OU noise, while applying the original full likelihood to every quadrature point. Sparse quadrature coefficients are signed integration coefficients and are never exposed as probability masses. The online wrapper commits an update only after its numerical checks pass; unresolved normalization cannot be used by direct_logpdf without explicitly requesting diagnostic access.

The implementation supports static normal or normal-score parameter priors, uncensored Gaussian observations, and declared executed controls. It does not support hierarchy, parameter drift, censored observations or compressed Gaussian history. Sensor declarations supply the observation and noise models; inference contains no seed, truth or sensor-suite selection. Physical moments are optional queries because nonlinear boundary transformations can require much more integration work than normalization or coordinate moments. They are not silently inferred from a Gaussian.

The rank harness is incomplete: it can evaluate marginal ranks and interval coverage across independent cooks, retaining failures and numerical uncertainty, but lacks joint/data-dependent ranks, predictive qualification and dynamic online acceptance studies. Its overall passed field is therefore false even if marginal gates pass. No eligible cook-level study, held-out sensor-suite study, long online qualification or real-cook validation was completed. Reserved seeds 21001–21064 remain unused. Seeds 23011/23012 were already exposed in an earlier phase and are not reserved validation data.

All 74 files in the previous curvature source manifest match their saved SHA-256 hashes, including production inference, physics, project dependencies and calibration. Baseline fingerprints remain estimator d31877a10f94 and physics c2c7bbf8c0ec. The source snapshot in this directory is the final version for this experiment; historical results were produced by earlier revisions during development. The driver history and raw logs retain those failures, but the historical revisions were not all separately frozen, so the final source must not be presented as a bit-for-bit reproduction of every earlier result.

Research informing the approach:

- Chen, Villa and Ghattas, [Hessian-based adaptive sparse quadrature](https://arxiv.org/abs/1706.06692): a Gaussian approximation can define numerical coordinates while the full target is still integrated. Their assumptions and convergence results are not a proof for this cook model.
- Modrák et al., [Simulation-based calibration checking test quantities](https://arxiv.org/abs/2211.02383): marginal checks alone can miss posterior failures; data-dependent quantities matter.
- [TensorCrossInterpolation documentation](https://tensor4all.org/TensorCrossInterpolation.jl/dev/): a possible separate deterministic compression approach, reviewed but not implemented here. Interpolation error and quadrature discretization error require separate checking.

A quasi-Monte Carlo trial was not started: clarification was requested about whether deterministic low-discrepancy point integration fits the user's no-Monte-Carlo constraint. No absence of a reply was treated as authorization.
The serialized frozen development fixture is results/core_case.jls; it requires Julia 1.11.9 and the matching BrisketEstimator module. Historical raw results use Julia JSON's NaN/Inf extension where computations were unavailable; the final-source result uses standard JSON null instead. Driver copies are archival records of their original workspace paths, not standalone programs to run inside this archive.
Final focused validation: 59 quadrature assertions, 28 transport assertions, 48 posterior/online API assertions and 16 validation-bookkeeping assertions passed (151 total), plus two settings-record checks in the final-source diagnostic. The API checks include accepted observations at time zero, correlated-noise prediction, a same-time forecast ownership check and rollback of an unresolved ten-second arrival. They do not establish accepted dynamic online operation. The final-source dynamic diagnostic retained a valid moment matrix but exhausted 59,993 evaluations in 102.7 seconds, returning unresolved with normalized state error 1.761448. Neither an independent statistical qualification nor real-time acceptance was achieved. The background worker was stopped after the experiment.
